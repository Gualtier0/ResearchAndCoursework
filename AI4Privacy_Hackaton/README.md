# AI4Privacy — Hackathon Project

Team **Dropped Neurons**

We explored using **LLMs (Llama-3.1-8B-Instruct)** to detect and mask **PII** with customizable privacy policies, improving on the benchmark **Piiranha-v1** model.

Our prototype scored **0.71 vs 0.70** on the “LLM-as-a-Judge” metric, showing better generalization and explainability.
