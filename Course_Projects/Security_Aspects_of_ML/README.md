# Security Aspects of Machine Learning

This folder collects a set of projects exploring **security and reliability issues in machine learning systems**, addressing both software-level vulnerabilities and hardware-based threats, as well as how to leverage ML systems to protect against such threats.

## Projects Overview

- **Anomaly Detection**  
  Implementation and evaluation of models for detecting abnormal behavior in datasets and systems.

- **Hardware & Trojan Detection**  
  Identification of malicious hardware modifications and Trojan circuits using supervised learning and feature-based pattern recognition.

- **Side-Channel Attacks (ASCAD)**  
  CNN-based key recovery from masked implementations in cryptographic devices, breaking ASCAD with **side-channel analysis (SCA)** attacks.
