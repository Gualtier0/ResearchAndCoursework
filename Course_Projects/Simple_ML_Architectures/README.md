# Simple Machine Learning Pipelines

Two educational machine learning pipelines developed as part of coursework.  
They implement a **minimal deep learning framework** from scratch using only NumPy, including forward and backward passes, gradient checking, and training routines.

- **Pipeline 1:** Implements the full ML framework (ReLU, Linear, Sequential, and Softmax-CrossEntropy modules) and trains a 3-layer network on a two-class spiral dataset.  
- **Pipeline 2:** Extends the same framework to train a simple digit classifier on **MNIST**, with a 2-layer architecture, validation split, and early stopping.  

Part of the code structure was **provided as a template**; all core logic (forward/backward passes, training loop, and validation logic) was implemented manually.
