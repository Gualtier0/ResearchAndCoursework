# Deep Learning Mini Projects

Four PyTorch implementations covering core neural network architectures:

## Project 1: Polynomial Regression
Gradient descent implementation for fitting polynomials to synthetic data.

## Project 2: CIFAR-10 CNN
Convolutional neural network for image classification with data augmentation and regularization.

## Project 3: IMDb LSTM
Bidirectional LSTM for sentiment analysis on movie reviews with pre-trained GloVe embeddings and truncated back propagation.

## Project 4: TSP Transformer
Transformer-based heuristic solver for the Traveling Salesperson Problem (20-city instances).

---

Each project is self-contained with data loading, model implementation, training pipelines, and evaluation.
